# MAX Chat Client — Тестовое задание (Фронтенд разработчик React)

## Деплой
Проект задеплоен на Vercel: [ссылка](https://green-api-liard.vercel.app/login)

Веб-интерфейс для отправки и получения сообщений через GREEN-API, по мотивам интерфейса MAX (web.max.ru).
> **Примечание**: задание выполнено для **WhatsApp** через GREEN-API (согласно допущению в ТЗ —
> "если вы не можете выполнить тестовое задание для мессенджера MAX, можете сделать для WhatsApp
> или Telegram"). Визуальный стиль интерфейса — по мотивам WhatsApp Web, а не web.max.ru.
## Стек
- React + TypeScript + Vite
- Tailwind CSS v4 (design tokens через CSS-переменные, container queries)
- Framer Motion (анимации, адаптивные переходы sidebar)
- Radix UI (Dropdown Menu, Tooltip)
- Sonner (toast-уведомления, подтверждение удаления)
- GREEN-API (https://green-api.com) — отправка/получение сообщений

## Функциональность

### Реализовано согласно ТЗ
- Авторизация через учётные данные GREEN-API (`idInstance`, `apiTokenInstance`) с валидацией статуса инстанса (`getStateInstance`) и восстановлением сессии из `localStorage`
- Создание нового чата по номеру телефона
- Отправка текстовых сообщений (`sendMessage`)
- Получение входящих сообщений через `receiveNotification` / `deleteNotification` (polling каждые 2.5 сек)
- Подгрузка истории переписки (`getChatHistory`)
- Список чатов (`getChats`) с последним сообщением и временем, локальное кэширование в `localStorage` с merge-стратегией (`mergeChats`)
- Интерфейс в стиле MAX/WhatsApp: список чатов, окно переписки, поиск по сообщениям, инфо о контакте

### Дополнительно (сверх ТЗ)
- **Отправка файлов и изображений** — через `sendFileByUpload` (GREEN-API поддерживает не только текст); поддержка изображений, видео, аудио, документов с превью и скачиванием
- **Прочитано/непрочитано** — реальный статус через `readChat` (не только локальный счётчик `unreadCount`, но и фактическая отметка "прочитано" на стороне WhatsApp)
- **Удаление сообщений** — через `deleteMessage`, с оптимистичным обновлением UI и контекстным меню сообщения (стиль WhatsApp Web: панель реакций + список действий)
  ⚠️ Активна только кнопка **Delete**. Остальные пункты меню (Reply, Forward, Pin, Star, Ask AI, реакции и т.д.) — визуальные заглушки для соответствия референс-дизайну, не реализованы функционально, так как не требуются по ТЗ (только текстовые сообщения между двумя сторонами)
- **Удаление чата** — локальное удаление из списка с подтверждением через toast
- **Автоскролл к новым сообщениям** — при открытии чата, отправке и получении нового сообщения окно плавно прокручивается к низу
- **Полностью адаптивный интерфейс** — единая логика на `useMediaQuery` вместо смешения CSS-брейкпоинтов и JS-состояния; на мобильном экране сайдбар и окно переписки переключаются как отдельные экраны (без наложения/дублирования разметки), список чатов использует CSS Container Queries (`@container`) для динамического масштабирования элементов при сжатии/расширении панели
- **Единая цветовая система** — вся палитра вынесена в CSS-переменные (`--max-*`) в `src/index.css` (фон, текст, primary-цвет, границы, цвета сообщений, тени и т.д.), а не захардкожена в компонентах. Смена акцентного цвета или любой другой правки палитры делается в одном месте, без правок в самих компонентах
- **UI голосового/видеозвонка** — демонстрационный экран звонка (таймер, mute, переключение аудио/видео режима, завершение).
  ⚠️ **Важно**: это визуальная имитация интерфейса, не реальный звонок — GREEN-API не предоставляет функциональности голосовых/видеозвонков, поэтому под капотом нет WebRTC-соединения. Добавлено как демонстрация UI-возможностей.

## Ход разработки (2 дня)

**День 1 — базовый функционал по ТЗ:**
- Настройка проекта (Vite + React + TypeScript + Tailwind v4)
- Авторизация через GREEN-API с валидацией и восстановлением сессии
- Основной layout приложения (сайдбар со списком чатов + окно переписки), по референсу web.max.ru
- Отправка и получение текстовых сообщений (`sendMessage`, `receiveNotification`/`deleteNotification` polling)
- Список чатов (`getChats`), история переписки (`getChatHistory`), локальное кэширование в `localStorage`
- Создание нового чата по номеру телефона

**День 2 — доработки, адаптив, полировка:**
- Отправка/приём файлов и изображений (`sendFileByUpload`)
- Реальный статус прочитанности сообщений (`readChat`)
- Удаление сообщений (`deleteMessage`) и чатов, с контекстным меню и подтверждением
- Полный адаптив под мобильные экраны (устранение рассинхрона CSS-брейкпоинтов и React-состояния, единая логика на `useMediaQuery`)
- Динамическое масштабирование элементов списка чатов через CSS Container Queries
- Унификация цветовой палитры по всему приложению через CSS-переменные
- Автоскролл к последним сообщениям
- UI-имитация голосового/видеозвонка (демонстрационная, без WebRTC)
- Тестирование и багфиксы адаптивной вёрстки, подготовка документации и деплой на Vercel

## Запуск локально

```bash
git clone <repo-url>
cd <project-folder>
npm install
npm run dev
```

Откроется на `http://localhost:5173`. На странице логина ввести `idInstance` и `apiTokenInstance` от своего инстанса GREEN-API (инстанс должен быть в статусе `authorized`).

## Сборка

```bash
npm run build

```


## Структура проекта
````
src/
api/green-api/ — клиент GREEN-API (createGreenApiClient, типы)
context/

hooks/
useChatsStore.ts — состояние чатов, polling, отправка/получение/удаление сообщений, read/unread
useMediaQuery.ts — единый источник правды для адаптивной логики (мобайл/десктоп)
lib/
chatsStorage.ts — персистентность чатов и выбранного чата в localStorage
layouts/
ChatLayout.tsx — общий layout: навигация, sidebar, адаптивное переключение
components/chat/
ChatHeader.tsx — шапка чата: поиск, звонки, контакт-инфо, удаление чата
ChatItem.tsx — элемент списка чатов (с container queries)
ChatList.tsx
ChatSidebar.tsx — сайдбар со списком чатов, фильтрами, созданием нового чата
ContactInfoDrawer.tsx — панель информации о контакте
MessageBubble.tsx — пузырь сообщения, контекстное меню, медиа
MessageInput.tsx
CallOverlay.tsx — UI-имитация звонка (не функциональный WebRTC)
pages/
Chat/ChatPage.tsx — окно переписки
Login/LoginPage.tsx
NotFound/NotFoundPage.tsx
router/
router.tsx — маршруты, ProtectedRoute
````
